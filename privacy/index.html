Privacy Policy

MartechSignal runs without accounts, without login walls, and without ads. That design choice does most of the work of a long privacy policy, but here is what you should know.

What we collect

Nothing about you as a person. The site sets no tracking cookies and runs no analytics that build profiles. No Google Analytics, no Meta Pixel, no heatmaps, no session recording. We can't show you a report on "users like you" because we don't have one.

Server logs exist because any web server keeps request logs for security and debugging: IP address, requested URL, user agent, timestamp. Cloudflare retains these under its standard settings, uses them to catch abuse and debug outages, and neither profiles readers with them nor sells them to advertisers.

Third-party requests

The pages load one third-party resource class: fonts from Google Fonts. That request sends your IP address and user agent to Google, which is inherent to how font CDNs work. Browser extensions like uBlock Origin block it, and the site falls back to system fonts when it's blocked.

Vendor links (the "Visit" buttons on tool reviews) go directly to the vendor's website. We don't insert redirect trackers, so we never know whether you clicked, and we couldn't tie it to you if we did.

Newsletter

If you subscribe to the weekly newsletter, we store your email address with our newsletter provider for exactly one purpose: sending you the newsletter. Every issue carries an unsubscribe link that removes you immediately. Your email is never sold or shared.

Contact

Questions about this policy can go through the site's GitHub repository discussions.
