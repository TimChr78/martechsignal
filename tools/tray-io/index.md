# Tray.io | MartechSignal review

AI-powered integration platform for building custom automation and AI agents

Tray.io, now trading as Tray.ai, calls itself an AI orchestration platform rather than an iPaaS, and the shift shows in what shipped during 2026. Tray Headless arrived in June with plugins for Claude Code and Codex plus a headless MCP server, followed by MCP dynamic authentication, Guardian Log Masking, and a Tray Sync CLI in August. The newest piece is Tray Helix, announced August 2026: a managed runtime that takes apps your team builds with AI coding assistants and puts them into production with IT visibility, security controls, and a named owner on each one.

The automation core still works the way the docs teach it: get data from one service, do something with it, send it to another. Workflows start from a service trigger, a webhook, or a scheduled poll, and the quickstart walks a Typeform-to-Google-Sheets template with a Slack notification, introducing project config, conditional logic, callable workflows, the data mapper, and environment variables along the way. Around that sits a catalog of 700-plus pre-built connectors, a connector SDK for anything missing, on-premise connectivity, API management, and an Embedded product for SaaS teams shipping integrations to their own customers.

AI is layered rather than bolted on. Every plan includes the AI Palette, VectorTables, and built-in AI tools, Merlin Build assists workflow construction, and the paid Agent Development add-on bundles Merlin Agent Builder with Agent Gateway, which turns those connectors into governed MCP tools with access control, observability, and cost governance.

Pricing is published as tiers but not as prices. Pro, Team, and Enterprise are described by workspaces, log retention, and insights windows, with HIPAA, SSO, regional hosting, and Tray IDP sold as add-ons and usage metered in Tasks. Teams that need agents governed inside a compliance boundary are the buyers. Small automation projects are not.
