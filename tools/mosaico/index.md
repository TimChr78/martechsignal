## Overview

Mosaico is a JavaScript editor for email templates, released under GPL-3.0 by voidlabs and running entirely on your own infrastructure. Its defining idea is that the editor does not decide what can be edited: each template declares its own editable blocks and style knobs, so the same editor can power a rigid corporate layout or a loose creative one. The repo ships one production template and a template language for making your own HTML Mosaico-ready. The live demo on mosaico.io is roughly the open-source library with a custom backend and a second template, which is a fair preview of what you get self-hosting. Integration is the real story: CiviCRM bundles it for nonprofit campaigns, Mailtrain has shipped it as its email editor since release 1.23.0, and an agency-oriented product (GoodEnough's Mosaico) is built around it. You run it with Node and Grunt, or via the bundled Docker images. Two honest caveats. It is a Knockout.js application from an earlier era of frontend tooling, and development has been slow: commits resumed in late 2026 after a quiet stretch, and there are no tagged GitHub releases, just the master branch and the demo. And there is nothing AI about it; it competes on being self-hosted and template-driven while hosted editors move toward generated copy. If your requirement is a self-hosted drag-and-drop editor you can embed in your own stack, with CiviCRM or Mailtrain heritage to prove it, Mosaico is the reference implementation.
