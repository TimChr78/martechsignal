Paperclip

Open-source control plane to manage AI agents like a company — hire, schedule, budget, and audit

Workflow Automation · Freemium · OPEN SOURCE

Overview

Paperclip takes a different approach to AI agents: instead of building individual automations, it runs an entire company. Think org charts, budgets, governance, and goal alignment, all for AI agents. Built as a Node.js server with a React UI, Paperclip is an open-source control plane that orchestrates teams of AI agents working toward a shared mission. You define the company structure (CEO, CTO, engineers, marketers) and agents check in on a heartbeat schedule, picking up tasks delegated through the org chart. Budget caps per agent stop runaway spend. Every decision is traced with a full audit trail. The key insight is that Paperclip doesn't run agents, it manages them. Agents run wherever they run and phone home. If you're using Claude Code, OpenClaw, or custom agents, they all slot into the same org chart. Multi-company support means one deployment can run several "companies" with complete data isolation. Paperclip is not a chatbot, an agent framework, or a workflow builder. It's the governance layer, not the worker. For marketing ops teams exploring autonomous agent fleets, Paperclip provides the missing management layer (who does what, how much it costs, and why decisions were made) that every agent experiment eventually needs.

AI Capabilities

  • Multi-agent orchestration (Claude, Codex, Cursor, Gemini, DeepSeek, Qwen, Hermes, OpenCode)
  • Per-agent budgets with auto-pause at cap
  • Approval workflows with scoped permissions
  • Scheduled routines (24/7 cadence)
  • Immutable audit log with one-click rollback
  • Pre-built company templates (167-agent agency, engineering teams)
