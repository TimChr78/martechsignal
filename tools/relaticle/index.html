Relaticle

Open-source CRM with native AI agent support, 30 MCP tools, REST API — Laravel & Filament

CRM · Open Source · OPEN SOURCE

Overview

Relaticle is an open-source CRM that launched in 2025 with a clear promise: give teams a free, modern CRM with no premium tiers, no locked features, and no per-seat pricing, forever. Built on Laravel 12 and Filament 3, it is a self-hosted CRM that covers contacts, companies, deals, pipeline management, and team collaboration. The Filament admin panel gives Relaticle a polished UI for an open-source tool, closer to a commercial SaaS than the typical Bootstrap admin panel. Laravel 12's testing improvements and Filament's component system keep the codebase maintainable and extensible for PHP developers. The "no premium tiers" commitment is the core differentiator. Unlike open-core models where key features sit behind a paywall, Relaticle ships everything for free. The tradeoffs are typical of a young open-source project. The feature set covers CRM basics well but lacks the depth of established players: no built-in email sequencing, no AI features, limited integrations, and a smaller community than tools like Twenty or Krayin. Documentation and onboarding are community-driven and thinner than commercial alternatives. The project is actively maintained but has less than a year of production history, so long-term stability and roadmap are still unproven. Relaticle fits budget-conscious teams that want a self-hosted CRM they fully own, Laravel shops evaluating options before committing, and organizations that value a no-strings-attached open-source model over feature depth. It is the right call when "free and self-hosted with a clean UI" is the top priority and AI features, extensive integrations, or vendor support can wait.
