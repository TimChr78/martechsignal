Open Mercato Review

The AI-Engineering Foundation Framework for CRM/ERP and commerce: open-source TypeScript, with multi-tenancy, RBAC, even

Agent Skills · Open Source · OPEN SOURCE

MartechSignal editorial review · updated 2026-08-31

Overview

Open Mercato is an open-source AI-engineering foundation for commerce and ERP/CRM projects: a TypeScript codebase where multi-tenancy, RBAC, event handling, and domain modules are pre-decided as conventions and specifications, so AI coding agents (Cursor, Claude Code, Codex) build features instead of re-deciding architecture on every prompt. The framing 'start with 80% done' is the honest pitch: you get commerce primitives (catalog, cart, checkout scaffolding) plus the platform plumbing that normally takes weeks, and your team, human or agent, fills in the differentiating 20%. The README documents a quick start with Docker, PostgreSQL, Redis, and JWT configuration, with separate setup paths for macOS/Linux and Windows. This is a foundation framework, not a product: there is no admin UI polish or marketing-tool surface to evaluate, and the right comparison is against starting a NestJS project from scratch, not against Shopify or a configured CRM. For teams that match the profile (TypeScript competence, custom commerce or marketplace ambitions, AI-assisted development workflow), it removes real ground work. Everyone else should look at configured platforms first.

Hands-on notes

Open Mercato bills itself as an AI-engineering foundation for commerce rather than a finished product, and that framing holds up: you get TypeScript scaffolding with multi-tenancy and RBAC wired in, then build on top. This is a developer's tool; there is no friendly admin onboarding path.

Pick it when you are standing up a custom commerce or marketplace backend and want commerce primitives handled. If you want a CRM you configure rather than code, look elsewhere.

Verdict

Strong foundation for engineering-led commerce builds; not a turnkey business tool.
