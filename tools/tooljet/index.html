ToolJet Review

Open-source low-code platform for internal tools: prompt or build admin panels, dashboards and operational apps

Workflow Automation · Free tier · OPEN SOURCE

Overview

ToolJet is an open-source low-code platform for building internal tools: admin panels, dashboards and operational apps that run on your existing databases, APIs and SaaS systems. The community edition is AGPL-3.0 and free to self-host; paid plans add SSO, audit logs and environments. Its 2026 direction is AI-first: ToolJet AI turns a description into pages, queries and components, and an MCP server lets your coding agent build against ToolJet's real component and data contracts, so the output is an editable ToolJet app rather than loose code. For marketing operations the use case is the same class as Appsmith and Budibase: campaign dashboards over ad-platform APIs, lead-quality consoles next to the CRM, and approval panels, all self-hosted so lead and consent data stays in-house. Trade-offs: AGPL matters if you expose modified versions as a service; the AI generation is quick but the result still needs someone who can check queries and permissions. At 40,000-plus GitHub stars it is among the largest projects in this class. We have not run ToolJet in production; this assessment is based on the documented architecture and public materials.
