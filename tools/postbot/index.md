## Overview

PostBot is an open-source content distribution tool from GitCoffee, built as a browser extension. You write an article, note, or post once, attach images, video, or audio, and it publishes to every platform you are logged into: the Chinese roster covers WeChat, Weibo, Toutiao, Xiaohongshu, Zhihu, Baijiahao, QQ, Weixin Channels, Douyin, Kuaishou, and Bilibili, and the architecture extends to X, Facebook, Instagram, TikTok, YouTube, and LinkedIn. A separate international build called Postar targets those platforms directly. The security model is its identity: publishing runs against your own browser's login sessions, locally, so no account credentials are stored in a cloud service. The default sync engine is deterministic and consumes no AI tokens; AI integration is optional. For automation, PostBot exposes MCP, a CLI, and a TypeScript SDK covering tasks, platforms, accounts, scheduling, and workflows, and it can drive pluggable engines including Playwright and several agent harnesses. That makes it one of the few multi-posting tools an agent can operate end to end. Caveats worth knowing. Documentation and the product UI are Chinese-first, which is a real friction point for teams outside that market. The license is Apache 2.0 with rider terms: the producer may relicense future versions, your contributions can be used commercially including in their cloud offering, and the interactive design is patent-protected. The main branch iterates daily; a stable branch (v1.1.20) is recommended for local runs.

## AI Capabilities

- Smart web reader that extracts content from pages for republishing
- Optional AI integration for content adaptation per platform
- Pluggable automation engines, including Playwright, PageAgent, OpenClaw, and agent harnesses
- MCP interface, CLI, and TypeScript SDK for scripted multi-platform distribution

## Pricing

PostBot is free to self-host.

Community edition free and open source, including all core sync and publishing features, with a default engine that consumes no AI tokens. A cloud edition and a separate international build (Postar) are offered by the vendor.
