AlphOne Review

Plugin-first open-source CRM written in Go

CRM · Open Source · OPEN SOURCE

MartechSignal editorial review · updated 2026-08-31

Overview

AlphOne is a plugin-first CRM with a Go backend exposing a JSON API and a React single-page frontend. The plugin architecture is the core design decision: features ship as separate plugins with their own repositories, so a team can run a minimal core and add exactly the modules it needs. The project publishes setup and self-hosting guides at docs.alph.one, and translation happens through POEditor with a weekly sync job rather than direct commits. Licensing is unusual and matters before you commit: the Go backend and SQL migrations carry the Elastic License 2.0, which forbids offering AlphOne to third parties as a hosted service, while the frontend, tests, and docs are AGPLv3. For a company that wants a self-hosted CRM it can extend in Go, that split is workable. For a SaaS vendor looking to resell hosted CRM, the backend license rules it out. With 179 stars the community is early-stage, and codecov badges suggest the project takes testing seriously for its age. Evaluate it as a foundation to build on, not a finished SuiteCRM replacement.

Hands-on notes

The README is short and the documentation lives on a separate docs site, which tells you where the project is in its lifecycle: the code and setup path are real (Go backend, React SPA, plugin repositories per feature), but the marketing surface is minimal. The plugin-first model means most evaluation effort goes into reading the plugin catalogue rather than feature pages. Claims here rest on the repository itself; we have not run a self-hosted instance.

The split license is the part to check first. Elastic License 2.0 on the backend means no offering AlphOne as a hosted or managed service to third parties, while the frontend carries AGPLv3. If your use case is internal CRM on your own infrastructure, neither restriction bites. If you build client solutions, read both licenses before writing any code against the API.

Verdict

A credible early-stage foundation for teams that want a self-hosted, plugin-extendable Go CRM and can live with the Elastic License on the backend. Too young to displace established open-source CRM options, and not usable for hosted-resale scenarios by license.
