Open-source martech momentum

Every morning we snapshot the GitHub stars of every open-source tool in our catalog that lists a public GitHub repository (69 of 80 open-source catalog tools, 80 of 162 catalog tools overall). A repository needs 5 daily snapshots before it appears on this page, which is why the charted set can be smaller. Inclusion rule, stated once: the catalog's open-source flag plus a GitHub repo URL. This page shows what moved in the window Aug 25 to Sep 27, 2026, tracked since Aug 25, 2026.

69 REPOS · 34 DAILY SNAPSHOTS · WINDOW 2026-08-25 TO 2026-09-27

Stars are a weak signal on their own. A repo can sit near the top of GitHub trending for a week on one HN post, and a 500-star project gaining 50 stars is a different story than a 40,000-star project gaining the same 50. The percentages below favor small bases for exactly that reason, so read the absolute deltas next to them. No projections here: just what the snapshots recorded, over the stated window, and nothing else.

Method

A scheduled script calls the GitHub API once per day for every open-source tool in the directory and stores stars, forks, open issues, and last-push date. This page is generated from those snapshots. The window is 2026-08-25 through 2026-09-27 (34 snapshots); tracking started Aug 25, 2026, so the page gets more accurate as the history grows. Nothing is annualized, extrapolated, or normalized. Stars measure attention, not usage or quality.
